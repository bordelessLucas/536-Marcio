# Brand Assets — CotaCondo

Assets oficiais da marca para uso na landing page, LP de fornecedores e área autenticada.

| Arquivo | Uso |
|---------|-----|
| `logo.png` | Header (lado esquerdo), favicon derivado, e-mails, PDF Whitelabel (marca plataforma) |
| `mascote.png` | Bloco institucional da LP (seção C — fundo branco/transparente) |
| `mascote-avatar-circular.png` | Avatar circular (fundo verde), ícones de chat/assistente, thumbnails |

## Paleta observada na marca

- Rosa / magenta → roxo → azul → teal/cian (gradiente do logo)
- Mascote: preto fosco + contornos neon magenta + olhos azul
- Tipografia do site: **Poppins** (wordmark do logo é asset gráfico; UI usa Poppins)
